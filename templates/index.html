Reservation System User Documentation

Parent/Guardian Instructions

  1. Open the Parent Slot List or Shared Calendar.
  2. View the available meeting times.
  3. Select an available time slot.
  4. Enter the parent or guardian name.
  5. Enter the student name.
  6. Click the Reserve Appointment button.
  7. A confirmation page will appear after the reservation is submitted.

If a time has already been booked, it will be shown as taken and cannot be reserved again.

Teacher Instructions

  1. Open the Teacher Portal.
  2. Sign in using the teacher email and password.
  3. Open the teacher dashboard.
  4. Add available meeting slots by entering the date, start time, and end time.
  5. View the scheduled and booked meeting slots.
  6. Check whether each time slot is open or booked.
  7. For booked appointments, view the parent or guardian name and student name.
  8. Remove a time slot if necessary.
  9. Log out when finished.
